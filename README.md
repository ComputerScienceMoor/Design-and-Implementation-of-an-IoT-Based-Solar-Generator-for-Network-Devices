# Design-and-Implementation-of-an-IoT-Based-Solar-Generator-for-Network-Devices
Abdulrahman kifayatullah Akorede (HNDNCC/24/016)
Design and Implementation of an IoT-Based Solar Generator for Network Devices with AC and Regulated DC Outputs (5V, 9V, and 12V).
This project focuses on designing and implementing a solar-powered generator that provides reliable and uninterrupted power for networking devices. It uses solar energy to charge a battery and supplies regulated DC outputs of 5V, 9V, and 12V, alongside a 220V AC output. The system also incorporates an IoT-based monitoring feature that allows users to remotely monitor battery voltage and power status, providing an efficient, affordable, and sustainable backup power solution for network devices.
